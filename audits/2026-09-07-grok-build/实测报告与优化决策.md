# Grok Build 候选技能实测报告与优化决策

## 结论

摘要的数据忠实性和引用一致性检查表现合格；quick审稿出现了对作者主张的误判。三个原生Agent实际完成了顺序交接，但父会话达到12轮上限，未正常收尾。最高优先级问题是报告角色输出了与本次过程不符的固定AI披露。

这些结果支持优先修正过程披露、审稿证据判断和验收器，而不是推翻现有写作能力或继续扩大Agent数量。本轮只保存实测证据与决策，没有修改正式技能、全局安装或发布版本。

- 候选技能：v0.3.1；实际Grok Build：1.0.13；init事件模型：`grok-4.6`；推理强度：medium。

- 两个早期预检因缺少Git项目根而加载全局版本，已停止并排除。正式运行采用独立任务目录，至多两个会话并发。
- 常用任务最多8轮/180秒，交接最多12轮/300秒；权限观察最多2轮。不启用Hook，不执行终端或外部检索，不调用MCP；材料为合成夹具，仍随推理调用发给Grok服务。
- 一份材料给出A组12/20、B组15/20，非随机、无协变量、不支持因果或真实人群推广。另一份虚构引用夹具包含年份不一致、缺文后条目及未被引用条目三个错误。

## 关键发现

### 1. 固定披露会生成未发生的研究过程

最终报告保留了以下固定描述：文献检索、来源核验、所有发现均按引用来源核实、全程人工监督。本轮禁止检索，也没有真实参考文献或上述核验记录，无法支持这些声明。

可追溯源为`skills/academic-research-suite/grok/agents/ars-report-compiler.md`第181至184行的AI Disclosure模板，其上游角色也保留同一段。实测产物见`outputs/pipeline-report.md`。这比措辞冗长更严重，应首先纠正。

### 2. 三Agent可以执行，父会话与验收仍需完善

本轮三个原生Agent都有启动回执、TaskOutput完成回执和各自的本地会话日志。研究架构师写第一阶段文件；综合Agent读取第一阶段文件并写综合材料；报告Agent读取前两份文件并写报告。

Messages格式流中的这些子调用均被标记为父session_id及空parent_tool_use_id。逐项对比独立子会话的tool_call_id后，全部写入均可归属到子会话，没有剩余父会话写入。这说明仅凭空parent_tool_use_id判定“父会话代写”的旧逻辑在本次Grok输出上会误判。

父会话机器终止原因为`error_max_turns`、12轮上限，非300秒超时，不能把这次结果继续归类为“Agent不可用”。子任务完成与整个父会话成功必须分别记录。

### 3. 模板负担与文件定位比包体积更值得处理

简单比较的综合材料有142行、8895字节，包含主张清单、跨论文冲突清单等；最终约200字报告也附带大段清单。摘要还猜错了一个模板路径。

建议提供精确模式文件索引，并在适用范围内区分轻任务和完整研究。完整研究要求的强制契约不能仅为缩短输出而删除；可探索将机器记录与用户正文分离，并验证其追溯关系。

Grok同时发现95个技能、106个命令，且本轮存在并发，因此不能把耗时和输入用量全部归因于ARS。还需用相同材料、相同模型和明确环境做多次对照。

### 4. 审稿需要判断问题的性质

默认审稿将“是否能证明因果关系”的提问视作作者肯定的因果主张。分类对照消除了该误判，但出现分类规则复述。正式优化应将分类放在评审过程内部：已承认局限、信息未提供、真正矛盾分别判断；每条意见有原文依据，允许无更多实质问题，避免按类别凑数。

## 优化顺序与验收条件

1. **P0：过程披露真实性。** 披露只能来自实际活动记录和证据状态。关闭检索、无引用或无人类过程审核时，不能出现相应完成声明。增加“无检索”“只有元数据”“部分核验”“没有人工审核记录”等对照材料。
2. **P0：验收器拆分判定。** 分开记录轨迹结构、工具执行错误、任务完成与内容质量。保留错误证据；通过子会话ID及tool_call_id恢复调用归属。不能因为一次可恢复读取错误就等同摘要错误，也不能把不实披露放过。
3. **P1：审稿证据分类与输出约束。** 分类仅用于内部判断；最终按用户要求输出。用新的未见夹具验证，避免对当前夹具过拟合。
4. **P1：轻任务模式与路径索引。** 摘要、引用检查和quick审稿只加载必需文件；准确列出模板名；正文不混入状态码和过程清单。用内容不回退、调用数减少和多次耗时分布验证。
5. **P1：父会话预算与收尾。** 调度预算覆盖发现、三次启动、三次等待和最终核对；保存阶段任务ID并支持续接。减少重复读取，不能只把上限无限调大。
6. **P1：权限与默认模式一致性。** 保留MCP工具暴露限制说明；验证真实子Agent工具表；统一各入口的native-phase/inline条件。Hook的write覆盖缺口仍待独立宿主测试，本轮未启用Hook，不能宣称它已被实测修复。
